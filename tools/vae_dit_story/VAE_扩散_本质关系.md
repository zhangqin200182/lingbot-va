# VAE ↔ 扩散:本质关系整理

> 这份文档整理自一段连续的讨论。所有数字都是当场算出来并核对过的(约 30 张图在同目录 `docs/`)。
> 顺序:**空间 → 扩散在做什么 → 条件如何进入 → 泛化/记忆化 → 四个对象的换算 → 防错清单 → 与 RL 的接口**。

---

## 0. 一句话

**VAE 提供「空间 + 回程票」(压缩到 `z`,再从 `z` 还原图);扩散提供「从 `N(0,I)` 到数据分布的搬运」。
VAE 缺的是搬运,扩散缺的是空间 —— 拼起来才是能生成的系统。**

```
像素 x ──encoder──▶ z ──decoder──▶ 像素 x̂          ← VAE:压缩器(不是生成器)
              │
              │  数据在 z 里的分布  p_latent(z) = ∫ p_data(x)·q(z|x) dx
              ▼
        N(0,I) ──[扩散的场 v_θ]──▶ p_latent          ← 扩散:搬运工
                                    │
                                    └─decoder─▶ 像素 ⇒ 生成
```

---

## 1. 空间:三套高斯,别混

| 符号 | 名字 | 谁给的参数 | 作用 |
|---|---|---|---|
| `q(z\|x) = N(μ(x), σ²(x))` | **VAE 编码后验** | encoder 输出(**每张图一套**) | **每张图 → 一个高斯团**(单峰) |
| `p(z) = N(0,I)` | **VAE 先验** | 固定,与 `c` 无关 | latent 空间的「背景」= 扩散的**起点** |
| `p_latent(z) = ∫p_data(x)·q(z\|x)dx` | **聚合后验** | 由上面两者混合 | 数据在 latent 里的**总体分布**(多峰/连通) |

**▶ 记号坑:** `q` 在 VAE 里是**学出来的近似后验**(有参数),在扩散里是**固定的前向高斯核**;`z` 既是"随机变量"也是"一次取值"。

### 关键不等式:先验空洞

```
p_latent ≠ N(0,I)

从 N(0,I) 抽 z:
  · 落在 p_latent 的【峰/脊】 ⇒ decoder 见过 ⇒ 出【好图】✓
  · 落在【空洞】里           ⇒ decoder 没见过 ⇒ 出【垃圾】✗

命中概率 = ∫_峰 N(0,I) dz    ⇒ 峰越窄越偏,越靠运气
```

**这就是「随机 `z` 解码出垃圾、但编码→解码很好」的解释。**
`β` 控制这个 trade-off:`β↑` ⇒ 峰被压平、更贴先验(命中率高、重建差);`β↓` ⇒ 峰更尖更偏(命中率低、重建好)。

### 为什么"点多峰"的归属容易错

```
q(z|x)        单峰(一个高斯,每张图一个)
p_latent      多峰/连通(因为对 x₀ 做了【边缘化】)
扩散的场      一个确定函数 —— 只负责【复现】p_latent
```
**⇒ 多峰属于「目标分布」,不属于 VAE,也不属于扩散。**
且真实 VAE 里 KL 会把 `p_latent` 抹平一些 ⇒ 常表现为"比先验更宽、更有结构",而非清晰分离的尖峰。

## 2. 扩散在做什么

### 2.1 插值与速度目标

```
x_t = (1−t)x₀ + t·ε ,   x₀ ~ p_data ,  ε ~ N(0,I) ,  两者独立
v*  = E[ε − x₀ | x_t] = (x − E[x₀|x_t]) / t
```

**为什么目标是 `ε−x₀`:** 直线插值 ⇒ 匀速 ⇒ `dx_t/dt = ε−x₀` 与 `t` 无关。

**训练时每个样本只碰一个 `t`**:不是"一步步扩散",而是**一行代数构造** `x_t` 再回归。

### 2.2 `x_t` 的边缘分布是什么

```
p_t(x) = ∫ p_data(x₀) · N(x ; (1−t)x₀ , t²I) dx₀

= 「缩放后的数据分布」⊛ 「各向同性高斯」
= 以每个 (1−t)x₀ 为中心、宽 t 的高斯、按 p_data 加权的高斯混合
```

```
t=0  ⇒ p_0 = p_data
t=1  ⇒ p_1 = N(0,I)          (精确!)
中间 ⇒ 一般【不是】高斯
```

**只有 `p_data` 本身是高斯时才仍是高斯**(高斯对卷积稳定):

```
p_data = N(μ,Σ)  ⇒  x_t ~ N((1−t)μ , (1−t)²Σ + t²I)
通用恒等式:      Cov(x_t) = (1−t)²Cov(x₀) + t²I
```

数值核对(`p_data=N(0,1)`):实测 Var 0.6808 / 0.4998 / 0.8157 vs 解析 0.6800 / 0.5000 / 0.8200 ✓
两原子数据则明显非高斯:t=0.3 超额峰度 −1.428(Shapiro p≈8e−45);t=0.8 时峰度 +0.002(p≈0.28)⇒ 已趋近高斯(高斯项占主导)。

### 2.3 「加一个高斯 = 新高斯」这条规则的边界

| `X` 是什么 | `X + N(0,σ²)` | 均值/方差 |
|---|---|---|
| **高斯** | **高斯** ✓ | 均值相加、方差相加 |
| 任意分布 | **不是高斯**(= `p_X ⊛ N(0,σ²)` 被抹平) | **均值不变、方差相加仍成立** |

**两条边界:**
- "均值相加、方差相加"只要求**独立**(方差可加性不需要高斯);
- "结果还是高斯"要求**两边都是高斯**。

> **扩散里严格成立的是「条件分布」`q(x_t|x₀)=N((1−t)x₀,t²I)`(x₀ 给定即常数);
> 一旦对 x₀ 积分拿到「边缘」`p_t`,一般就不再是高斯。**

## 3. 条件如何进入

### 3.1 只换先验因子,不动几何因子

```
w(x₀ | x_t) = 先验(x₀) × 高斯(x_t ; (1−t)x₀ , t²I)
              └ ① ┘     └──── ② 几何项 ────┘

无条件:  ① = p_data(x₀)
有条件:  ① = p_data(x₀|c)      ← 只有这项变
         ② = 完全不变          ← "离 x_t 多近"与语言无关
```

**⇒ "每个 `c` 有自己的场" = 同一组高斯、同一套几何,只换了「候选的先验权重表」。**

数值(`x_t=0.4, t=0.5`,四候选):

| 候选 `x₀` | −1.0 | −0.2 | +0.6 | +1.0 | `E[x₀\|x_t]` | 位移 `(E−x)/t` |
|---|---|---|---|---|---|---|
| 几何项(两者相同) | .072 | .219 | .355 | .355 | — | — |
| 无条件权重 | .072 | .219 | .355 | .355 | **+0.452** | +0.104 |
| 有条件权重 | .011 | .033 | .319 | **.638** | **+0.812** | **+0.823** |

### 3.2 「范围收缩」是【软】的

```
硬范围(支撑):{x₀ : p_data(x₀|c) > 0}     ⇒ 通常一个都没删
软范围(有效候选数):N_eff = 1/Σw²          ⇒ 这才是"范围"的量化
```

`t=0.5` 时:`N_eff` **3.28 → 1.96**(压掉 40%)。

### 3.3 ★ 条件与几何的"话语权"随 `t` 衰减

固定点、量 `|E_cond − E_uncond|`:

| `t` | 0.90 | 0.70 | 0.50 | 0.30 | 0.15 | 0.05 |
|---|---|---|---|---|---|---|
| `\|ΔE\|` | **0.602** | 0.529 | 0.360 | 0.159 | **0.006** | **0.000** |

```
t 大 ⇒ 高斯项平坦 ⇒ 后验≈先验 ⇒ 【语言主导结构】
t 小 ⇒ 高斯项尖锐 ⇒ 后验≈点质量 ⇒ 【采样路径主导细节】
```

**这不是玄学,是 `p(x₀|x_t) ∝ p_data(x₀|c)·N(x_t;(1−t)x₀,t²I)` 里高斯因子宽度 `t/(1−t)` 的直接结果。**

### 3.4 盆地边界:条件移动的是它

ODE 下 `x₀ = F_c(ε)` 是确定性映射 ⇒ `H(x₀|ε,c) = 0`:
**结局在 `ε` 抽到的瞬间就被决定**(但"决定"是计算意义上的必然,不是"`ε` 里存着构图")。

**"锁定在高噪声"与"ε 决定"是同一件事:** 锁定 = `ε` 落进哪个盆地,而**盆地的边界是「场」的性质** ⇒ `c` 移动的就是它:

| 条件强度(两模式权重) | 盆地边界 `ε*` |
|---|---|
| 0.5 / 0.5(无条件) | **0.0000** |
| 0.7 / 0.3 | −0.5249 |
| 0.9 / 0.1 | **−1.2827** |
| 0.99 / 0.01 | **−2.3281** |

```
同一个 ε=+0.15:权重 0.9/0.1 → 终点 +1.0000 ;权重 0.1/0.9 → 终点 −1.0000
ε=0 处(几何打平)  ⇒ 只有条件能做决定
```

### 3.5 「遵从性」≠「确定性」

```
p(z₀|c) 是一个【分布】(支撑在"符合 c 的图"上),不是单点
⇒ 同 prompt 内部【仍有巨大多样性】
⇒ 但"不符合 c 的图"概率很低
⇒ 听话说的是【分布的支撑/集中度】,随机说的是【分布内的多样性】
```
(这也是 RL 能工作的前提:同 prompt 采 K 个、奖励不同。)

## 4. 泛化 与 记忆化

### 4.1 训练看到的是离散的 `p̂`

```
训练:p̂_data = (1/K)·Σ_k δ(x − x_k)      ← K 个 δ,支撑是 K 个点
真实:p_data                              ← 我们从来没有它
```

### 4.2 那"连续"从哪来?三处

| 来源 | 作用 |
|---|---|
| **① 高斯核** | `E_p̂[x₀\|x_t] = Σ_k w_k x_k`,`w_k ∝ N(x_t;(1−t)x_k,t²I)` ⇒ **目标函数本身光滑** |
| **② 有限容量 + 平方损失** | 网络**造不出** K 个零测度吸引子 ⇒ 只能平滑插值 |
| **③ 每步重抽 `(t,ε)`** | 每张图贡献**一条线**(无穷多训练对),不是**一个点** |

```
数据:离散 ⇒ 训练约束落在 K 条"线"上
场  :连续 ⇒ 线间由"平滑先验"插值
采样:走线间 ⇒ 输出是插值点 ⇒ 不在训练集
```

### 4.3 「会不会被 K 条线困住?」——理论上会

用 `p̂ = 20 个 δ` 精确建场,2000 个随机起点跑 ODE:

```
到最近训练点的距离:中位数 0.00e+00,最大 2.44e-03
距离 < 1e-3 的比例: 99.4%
⇒ ODE 的像【就是】那 20 个原子
```

**⇒ 这不是 bug,是"完美拟合"的必然:** 概率流 ODE 保分布 ⇒ 像只能是 `p̂` = K 个原子。
**记忆化 = 训练太成功;泛化 = 正则化效应。**

**脱困机制(按有效性):**

| # | 机制 | 为什么有效 |
|---|---|---|
| ① | **VAE 编码噪声** | 训练目标是 `z~q(z\|x)=N(μ,σ²)` ⇒ `p̂` 在 latent 里已是 **K 个高斯团** ⇒ 像 = K 个**有体积的团** |
| ② | **条件 `c` 的插值** | 对未见 `c` 在 `c` 维度插值 ⇒ 训练集里没有的**组合**(最便宜的一条) |
| ③ | 有限容量/平滑性 | 场被糊开,团间也有可靠值 |
| ④ | SDE / 数值误差 | 轨迹被抖散 |
| ⑤ | 早停 / 数据增广 | 破坏"精确拟合 `p̂`" |
| ⑥ | `K` 巨大 | 团间距 < 团宽度 |

**对照实验(连续 `p_data`):** `U[−1,1]` + 20 个训练点,3000 个终点:**100% 落在支撑内、0 个与训练点重合**(std 0.574 vs 均匀分布 0.5774)⇒ 旧的是**分布**,新的是**实例**。

**可测:** 记忆化指标 = 生成样本到最近训练样本的距离。

## 5. 四个对象的换算(完整推导)

记

```
x_t = (1−t)x₀ + tε ,  x₀ ~ p_data ,  ε ~ N(0,I) ,  独立
μ(x) := E[x₀ | x_t=x]        ← 后验均值(一个【场】)
v(x,t) := E[ε − x₀ | x_t=x]   ← 流匹配回归目标
s(x) := ∇_x log p_t(x)        ← score
```

### 5.1 两个零件(整套推导只用这两个)

```
零件 1(代数):   ε − x₀ = (x − x₀)/t
零件 2(微积分): d/dx N(x;m,v) = −N(x;m,v)·(x−m)/v
```

### 5.2 六条换算

| 从 → 到 | 公式 |
|---|---|
| **μ → v** | `v = (x − μ)/t` |
| **μ → s** | `s = ((1−t)μ − x)/t²` (Tweedie) |
| **v → μ** | `μ = x − t·v` |
| **v → s** | `s = −(x + (1−t)v)/t` |
| **s → μ** | `μ = (x + t²s)/(1−t)` |
| **s → v** | `v = −(x + t·s)/(1−t)` |

**数值锚点**(两原子 ±1,等权,`x=0.1, t=0.5`):

```
p_t = 0.4839 ,  μ = +0.1974 ,  v = −0.1948 ,  s = −0.0052
六条换算全部互相吻合 ✓(数值微分 d/dx log p_t = −0.0052 也吻合)
```

### 5.3 推导要点(只列关键步)

```
A. v = (x−μ)/t
   零件1 + 取条件期望;条件下 x、t 都是常数 ⇒ 提出去

B. s = ((1−t)μ − x)/t²   (Tweedie)
   dp_t/dx = ∫p_data·[−N(·)(x−(1−t)x₀)/t²]dx₀          ← 零件2
          = −(1/t²)·p_t(x)·E[x−(1−t)x₀ | x_t=x]        ← 用 Bayes 把积分写成期望
   两边除以 p_t(x),再用 E 的线性:E[x−(1−t)x₀|·] = x − (1−t)μ

C,D 其余四条 = 上面两条的代数反解
```

### 5.4 唯一不可逆的一步,以及信息为什么没丢

```
✗ p(x₀|x_t) → μ :积分,丢信息(单点的后验分布 → 一个向量)
✗ μ → p(x₀|x_t) :恢复不了(0.5δ(+1)+0.5δ(−1) 与 δ(0) 均值都是 0)

✓ 但 μ(·,t) 在【所有 x、所有 t】上
   ⇒ 定出整张 score 场 ⇒ 定出 p_t(差一个常数,归一化后可定)
   ⇒ t→0 定出 p_data
```

> **丢的是"单个 `x_t` 处的后验形状",得到的是"整个场的结构" —— 后者足以重建整个分布族。**
> 这也是为什么"只学均值"是可行的:**完整后验是 `R^d → 分布` 的映射(无法参数化);均值场是 `R^d → R^d` 的向量场(可参数化)**。

### 5.5 三个"差"的含义

| 差 | 含义 | 备注 |
|---|---|---|
| `ε − x₀` | **全程位移**(与 `t` 无关) | 训练目标 |
| `x − x₀` | **已走位移** `= t(ε−x₀)` | 零件 1 |
| **`x − μ`** | **离后验均值多远** `= t·v` | **决定"这一步往哪走"** |

**三者都是带符号的位移向量,不是距离**(取范数才是长度)。

### 5.6 为什么这些量"有用"而 `p_t` 本身"没用"

```
p_t(x_t)  = ∫… 高维积分,算不出来
∇log p_t  = −(x + (1−t)v_θ)/t   ← 由网络直接给出

⇒ 所有需要 p_t 的算法(SDE 补偿、CFG、RL 的似然)实际只用 score
⇒ 核心转圜:把「估计密度」换成「估计密度的梯度」
```

**一个网络三种用途:** ODE 直接用 `v_θ`;SDE/CFG 换成 `s`;RL 的每步 `log π` 用 mean+variance。

## 6. latent 扩散的实现细节(为什么 patchify 不破坏一致性)

**判据:噪声加在哪、损失算在哪、ODE 积分在哪。三处都在 `z` 上 ⇒ 就是"在 VAE latent 上扩散"。**

代码事实(Wan 实现):

```
patch_size=[1,2,2];  patch_embedding_mlp = Linear(192, 3072)  ⇒ in_channels = 192/4 = 48
输入: rearrange('b c (f p1) (h p2) (w p3) -> b (f h w) (c p1 p2 p3)')  ← 纯重排(无损)
      + Linear(48·4 → 3072)   ← 单射(升维嵌入)
输出: proj_out = Linear(3072, 48·4=192) + unpatchify ⇒ 回到 latent 形状
docstring:返回 [C_out, F, H/8, W/8]   ← H/8 正是 VAE 的 8× 下采样
```

**⇒ 网络是 `z → z` 的向量场;patchify/embed 只是内部表示(③),不改变扩散空间(②)。**

| 变了 | 没变 |
|---|---|
| 内部度量(attention 在 3072 维算相似度) | 噪声分布 `N(0,I)`(在 `z` 空间) |
| 内部归纳偏置(patch 内像素线性混合) | 插值路径、损失、边缘分布、ODE 正确性 |

**只有一种情形真会"不一致":把扩散搬到另一个空间(像素 / 离散码本)去做 —— 那时需要配套不同的 VAE。**

## 7. 防错清单:四个二分

```
1. 随机变量 vs 取值        x_t / x ,  z / z
2. 分布 vs 点              p_latent / 一个 z ,  p(x₀|x_t) / 一个 x₀
3. 单次采样 vs 多次采样    终点确定 / 落在不同盆地
4. 密度 vs 密度的梯度      p_t 算不出 / ∇log p_t 可算
```

**每次卡住,基本都是踩了其中之一。** 另外两个高频坑:

- **`s` 是对 `x_t` 求导,不是对 `x₀` 求导**(score ≠ 后验的梯度);
- **不要写成 `p(x₀)·p(x₀|x_t)`**:那是"先验平方",等价于偷偷把条件对比度加了一档(无条件时看不出,有条件时会过度顺从)。

## 8. 与 RL(附录 A / B)的接口

这套"空间 + 分布"的语言,正好是那两条 RL 路线的前提:

| RL 概念 | 在这套语言里是什么 |
|---|---|
| 策略 `π_θ` | 每步 `N(mean_θ(z_t,t,c), s²)`(在 `z` 空间) |
| 似然 | 每步高斯密度 ⇒ **必须把 ODE 换成 SDE** |
| 优势 `A` | 组内相对奖励(`z₀` 打分后算) |
| **RL 改的是什么** | **`p(z₀\|c)` 的形状**(往高奖励区域偏),不改空间、不改 T |
| **RL 学不到什么** | 新能力(容量/空间不变)⇒ 只能在已有支撑内偏移 |
| DiffusionNFT 的目标 | 把奖励写进**前向回归**的权重,不碰采样器 |
| off-policy(η) | 采集策略与训练策略的滞后 ⇒ 用对 SFT 是"目标漂移",用对 RL 是"偏差" |

**⇒ RL 只在"第 2 节那个分布"上做偏置,不动"第 1 节那个空间"。**
