Wan2.2 VAE + DiT:从像素到生成

VAE latent 与视野 · DiT 的先验/后验/引力场 · 条件作为一块"透镜"
一句话:VAE 把像素压成 8×8×48 的 latent(平滑、冗余、通道尺度不均);DiT 在 latent 上学一个"多引力加权合成"的速度场, 把各向同性的 N(0,I) 搬运成高度各向异性的数据分布;而条件只改先验 —— 等于给这些引力加一块按条件调音量的透镜。
第一幕 · VAE 与视野 第二幕 · 先验/后验/引力场 第三幕 · 条件 = 透镜 术语与边界

第一幕VAE:像素 ↔ 8×8×48 的 latent

先看形状,再看"视野"和"冗余",最后看"通道尺度不均" —— 这三点决定了后面 DiT 面对的是什么样的分布。

1.1 形状流水线

128×128 图像
  → patchify 2×2        → 64×64×12
  → 编码器(3 次下采样)  → 8×8
  → 96 通道 = 48 mean + 48 logvar
  → z = μ + σ·ε         → latent 8×8×48
  → 解码器(3 次上采样)  → 64×64×3
  → unpatchify 2×2      → 128×128
组件数量
WanCausalConv3d62(编码 26 + 解码 34)
WanAttentionBlock2(编/解码各 1 个 mid-block)
普通 Conv2d10

双相机时,两个相机的 latent 在宽度方向拼接:128×128×2 → latent 8×16。

1.2 "8×8×48" 该怎么读

不是"一个 48 维高斯",而是:每个空间位置各有一个 48 维对角高斯(每位置自己的 μ 和 σ);一帧有 8×8 = 64 个这样的高斯。48 个通道之间独立(对角),但尺度差别很大。

1.3 视野:一个 latent 单元能"看到"多少像素

1.71 → 29.16RF σ(px),17 倍
8.6×中心半径 vs r90(中心强、边缘弱)
0.9959相邻 latent 的视野相似度
≈121 帧时间视野(时间下采样 4×)

这三点的含义:latent 空间是平滑的、有冗余的、越深越"全局"的。所以 DiT 面对的不是 24,576 个独立变量,而是一个高度相关的场。

第二幕DiT:先验、后验、引力场

这一幕只回答一个问题:为什么"每一步都取平均",最后却能生成合法的样本?

2.1 训练一步到底在算什么

x0      = latent                          # 干净 latent
eps     = torch.zeros_like(x0).normal_()  # ε ~ N(0, I)
sigma   = 逐帧随机                          # 噪声水平
x_sigma = (1-sigma)*x0 + sigma*eps        # 网络的输入
target  = eps - x0 = (x_sigma - x0)/sigma # 网络要输出的东西
loss    = || net(x_sigma, sigma[, c]) - target ||²
配置一个 chunk 的 latentlatent token网络输出行数action token
LIBERO(128×128×2)[1,48,4,8,16] = 24,576 数12851216
demo(256×256×2)[1,48,4,16,32] = 98,304 数512204832
franka(224×320×3)[1,48,4,14,60] = 161,280 数840336080
robotwin(tshape)[1,48,2,24,20] = 46,080 数24096032

模型 30 层、inner_dim 3072、5.09 B 参数(meta 设备实跑确认)。输出是 token 序列 [1,512,48],经 data_seq_to_patch 还原成 [1,48,4,8,16](512×48 = 24,576 ✓)。

2.3 为什么"平均"是对的:训练的真实机制

数学上,平方损失的最优解是条件期望;而条件期望按定义就是后验加权平均。实现上更直接:

落在同一个读数附近的训练样本,其 x₀ 的比例恰好等于后验(贝叶斯的直接后果)。 所以对它们的 target 取普通算术平均,就等于后验加权平均。

顺带说明:"同一小段读数"不是代码里的步骤,而是网络平滑性造成的分辨单元。邻域越窄越接近逐点条件期望(0.2 → −0.175;0.01 → −0.1947;→0 → −0.19475)。

第三幕条件:给引力场加一块透镜

这一幕只有一句话:条件不增加源的个数,只改每个源的权重。

3.1 数学上:只换先验

无条件:  p(x₀ | x_σ, σ)     ∝  p_data(x₀)  · N(x_σ; (1−σ)x₀, σ²I)
有条件:  p(x₀ | x_σ, σ, c)  ∝  p(x₀ | c)   · N(x_σ; (1−σ)x₀, σ²I)
                                 └── 只有这一项被换掉(先验)──┘
问题答案
似然变了吗?没变 —— 加噪是在 x₀ 上做的,与 c 无关
源的个数变了吗?没变 —— 改的是每个源的权重;权重被压到 0 时效果上等同"删源"
训练要算先验吗?不要 —— 样本是 (x₀, c) 配对抽出的,"先验"就是"带这个 c 的样本构成"

3.2 代码级:条件从哪进模型

训练时把四段拼成一条序列,用一张掩码规定谁能看谁:

hidden_states = torch.cat([noisy_latent,            # ← 参与损失
                           clean_latent,            # ← 条件
                           noisy_action,            # ← 参与损失
                           clean_action], dim=1)    # ← 条件
latent_hs, _, action_hs, _, _ = torch.split(...)    # 条件段输出被丢弃
查询 → 键允许?规则
条件 → 条件✅仅因果
加噪 → 条件✅因果,但排除自己所在的帧块 ← 条件就是从这里进入 target 的
加噪 → 加噪✅仅同一帧块内
条件 → 加噪❌禁止

加噪只加在 target 上:条件帧默认干净,但有 50% 概率被额外加噪(noisy_cond_prob=0.5,噪声水平取高区间 0.5~1.0;action 分支为 0.0)—— 训练模型容忍"脏观测",因为自回归 rollout 时条件帧正是模型自己上一步的输出。

推理时改为:观测帧先跑一次把 K/V 存进 attn_caches,之后每步只送 noisy latent;文本仍走 cross-attention。 "无条件"= 换掉条件,不是另一个模型:noise_pred = uncond + guidance_scale * (cond - uncond)。

3.3 透镜的三条性质

#性质含义
①乘性权重 = 先验 × 似然,条件乘在先验上 → 不能凭空造源(数据里没有的,条件也照不亮)
②按样本/类别调不是按位置连续调;更像"一排音量旋钮",每个 c 一张设定表
③连 σ=1 的靶心一起改E[x₀] → E[x₀|c],从第一步就偏置,不只是后期

拔河:若条件指向 −1(先验 0.9/0.1)而读数偏向 +1(似然 0.579/0.388),则后验 = 0.858 / 0.142 → 条件赢。 条件足够强时能压过读数的倾向 —— 这就是"可控"的来源。

术语、五个易错点与准确性边界

五个最容易误解的点

#误解正确
1σ 是 ε 的方差σ 是混合比例 / 标准差;Var(σ·ε) = σ²;σ 与 t 只差 1000 倍
2后验是高斯一般不是 —— 它继承 p_data 的形状,可能多峰
3训练要算概率一次都不算;先验来自样本构成,后验加权来自"抽样 + 平均"
4采样要还原某个 x₀采样时没有"原本的 x₀";只要求落点分布正确
5条件改了加噪/模型条件不改加噪、损失、采样循环;实现上只是"多一组 K/V",数学上只是"换先验"

准确性边界(哪些是实测,哪些是近似)
  • 实跑确认:DiT 形状与参数量(meta 设备前向)、贝叶斯计数的每个数字、切口公式 Φ⁻¹(1−π)、轨迹不交叉/可逆、比例恒定 0.4830。
  • 权重无关的线性化近似:VAE 视野测量(逐路径计数;attention 视为"残差 + 均匀全局混合";空间只算单帧 T=1)。
  • 随机初始化权重:视野的 autograd / 扰动验证列用的是随机 VAE 权重(seed 0);真实训练权重的 ERF 需拿真权重重跑(probe_rf.py --vae-path)。
  • 玩具模型:1 维两点数据(±1)的所有数字都是精确解,但常数(0.618、1/σ²、1/σ³)是两点数据特有的;真实 24,576 维的常数不同,但两条定性机制(判别力随 σ 暴涨、中点稳定性翻转)普遍成立。
