⑤ 方法与口径

量是什么

  • 编码方向：固定最深层的一个单元（latent 单元），反向传播到输入像素，得到该单元的有效感受野（ERF）强度分布。每一层都可以给出「该层单元 → 输入像素」的分布，于是能看到视野逐层变大。
  • 解码方向：固定一个 latent 单元，向前传播得到它对输出像素的影响域；反过来固定一个输出像素，反向传播得到它依赖的 latent 集合（逐步收缩）。
  • 强度用路径计数（把每个卷积、每条残差/捷径支路都按等权线性化）计算，因此只依赖网络几何（核大小、步长、填充、支路结构），与训练权重无关。
  • 注意力块按均匀混合处理（残差 + 全图平均），这是权重无关口径下唯一自然的选择；它会在局部 blob 之外加一层很低的全局底噪。

为什么不用“理论感受野”

理论感受野（支撑集）在第三个下采样块之后就已经覆盖整幅 128 px，之后一直是 100%；真正在变化、也真正决定“中心强、边缘弱、邻近高度相似”的是有效感受野。所以本页同时给出支撑范围（阈值轮廓）和 σ / r50 / r90 这几个有效半径。

用真实权重复现

几何口径与权重无关；上表 autograd 列的权重来源：随机初始化（seed 0）。把训练好的 VAE 目录接上即可得到真实曲线，几何部分会按 checkpoint 的 patch_size 与残差块结构自动重建：

python probe_rf.py --vae-path /path/to/pretrained/model/vae
